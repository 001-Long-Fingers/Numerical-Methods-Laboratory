## `[ 01 ]` Overview

The **Statistics** module provides numerical and visual implementations of the most fundamental concepts in computational statistics and probability theory.

The objective is not only to compute statistical quantities, but also to **develop intuition** through interactive simulations and graphical demonstrations.

The module aims to become a computational laboratory where users can:

| # | Capability |
|---|------------|
| → | Simulate stochastic processes |
| → | Model discrete probability experiments |
| → | Study convergence to limiting distributions |
| → | Generate and test pseudo-random sequences |
| → | Visualize probability distributions |
| → | Explore the Central Limit Theorem experimentally |
| → | Analyze variance, bias, and estimator behavior |

## `[ 04 ]` Visualization Goals

Every algorithm should include an accompanying visualization wherever possible.

| Algorithm | Visualization |
|-----------|---------------|
| **Random Walk Model** | Trajectory paths and displacement distribution over time |
| **Urn Model** | Live draw animation with running composition of the urn |
| **Gaussian Analysis** | Histogram of samples converging to the normal curve |
| **Random Number Sequence Generator** | Scatter/lag plots exposing periodicity and correlation |
